จัดการระบบ
กำหนด Role ให้สมาชิก
สร้างบัญชีผู้ใช้ให้สมาชิก
สร้างบัญชี Firebase Auth สำหรับทุกเบอร์โทรใน Firestore ที่ยังไม่มีบัญชี
• มีอีเมล์ → ใช้อีเมล์นั้น  • ไม่มีอีเมล์ → สร้างเป็น เบอร์@tat32.app
* รหัสผ่านเริ่มต้น: 123456  · สมาชิกเปลี่ยนได้ภายหลัง
แก้ไขข้อมูลสมาชิก
วิธีแก้ไขข้อมูลสมาชิก:
ไปที่แท็บ "ทำเนียบรุ่น" → กดที่การ์ดสมาชิก → กดปุ่ม "แก้ไขข้อมูล"

สิทธิ์การแก้ไข:
• Admin — แก้ไขได้ทุกคน + กำหนด role
• Editor ตร. — แก้ไขได้เฉพาะสมาชิก ตร.
• Editor ทบ. — แก้ไขได้เฉพาะสมาชิก ทบ.
• Editor ทอ. — แก้ไขได้เฉพาะสมาชิก ทอ.
• Editor ทร. — แก้ไขได้เฉพาะสมาชิก ทร.
• Member — แก้ไขได้เฉพาะข้อมูลตัวเอง (เบอร์/อีเมล์/ไซร์เสื้อ/รูปภาพ)
ซิงค์ข้อมูล Sheet → Firebase
นำเข้าข้อมูลสมาชิกทั้งหมดจาก Google Sheet เข้า Firebase (collection: members)
หลังจากนำเข้าแล้ว แอปจะอ่านข้อมูลจาก Firebase เป็นหลัก ไม่ต้องพึ่ง Sheet อีก
* รูปภาพเก็บ URL ไว้ใน Firebase (ไฟล์ภาพจริงยังอยู่ใน Google Drive)
ลบข้อมูลสมาชิก
กรอกเงื่อนไขอย่างน้อย 1 ข้อ แล้วกด "ค้นหา" เพื่อดูรายชื่อก่อนลบ
⚠️ ลบแล้วไม่สามารถกู้คืนได้
นำเข้ารูปภาพ → Firebase Storage
ดาวน์โหลดรูปสมาชิกจาก Google Drive แล้วเก็บใน Firebase Storage แยกตามเหล่า
member-photos/{branch}/{id}.jpg
* รูปที่อยู่ใน Storage แล้วจะถูกข้าม · ต้องตั้ง Storage Rules ให้ Admin เขียนได้
นำเข้ารูปภาพจากไฟล์ในเครื่อง (เรียงตามลำดับ)
เลือกไฟล์รูปที่ตั้งชื่อเป็นตัวเลขลำดับ เช่น 1.jpg, 2.jpg, 3.jpg (ข้ามเลขได้ ไม่ต้องเรียงติดกัน) ระบบจะจับคู่ตามลำดับไฟล์กับลำดับสมาชิกในเหล่าที่เลือก (เรียงตาม id จากน้อยไปมาก) ไม่ได้ใช้ตัวเลขในชื่อไฟล์จับคู่กับ id โดยตรง
* ไฟล์ที่ 1 → สมาชิกคนแรกของเหล่า, ไฟล์ที่ 2 → คนถัดไป ฯลฯ
อัพเดท Sheet อัตโนมัติ (Google Apps Script)
วาง URL ของ Google Apps Script Web App ด้านล่าง เพื่อให้แก้ไขข้อมูลแล้วอัพเดทใน Sheet พร้อมกัน
ดูวิธีติดตั้ง Apps Script ▶
วิธีติดตั้ง / อัพเดท:
1. เปิด Google Sheet → Extensions → Apps Script
2. ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดด้านล่างแทน
3. กด Deploy → New deployment (หรือ Manage → Edit → New version)
4. Execute as: Me / Who has access: Anyone
5. คัดลอก URL ใหม่ที่ได้มาวางในช่องด้านบน แล้วกด 💾 บันทึก
6. กด 🔗 ทดสอบ — ถ้าเห็น {"ok":true} แสดงว่าพร้อมใช้งาน

โค้ด Apps Script:
ส่งออกรายชื่อสมาชิก
ส่งออกข้อมูลสมาชิกทั้งหมดที่โหลดอยู่ในขณะนั้น
* Excel: เปิดได้ทันที · PDF: กด Ctrl+P แล้วเลือก Save as PDF
นำเข้าข้อมูลจากไฟล์ Excel
นำเข้าข้อมูลสมาชิกจากไฟล์ Excel (.xlsx / .xls) เข้า Firebase โดยตรง
* แถวแรกต้องเป็น header · ระบบจับคู่คอลัมน์อัตโนมัติจากชื่อหัวตาราง
ตั้งค่าหน้าประชาสัมพันธ์
เพิ่ม/แก้ไขประกาศที่แสดงในแท็บ ประชาสัมพันธ์
จัดการกิจกรรม
สร้างกิจกรรม เช่น งานเลี้ยงรุ่น พร้อมกำหนดตัวเลือกฟอร์มแสดงความจำนงสมาชิก
ลิงค์อัลบั้มภาพถ่าย
วางลิงค์อัลบั้มภาพที่ต้องการแสดงในแท็บ ภาพถ่าย (เช่น Google Photos)
